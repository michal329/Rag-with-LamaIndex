# מטלות Agentic Coding

## מהו Agentic Coding?
Agentic Coding הוא שימוש בכלים כמו Cursor, Claude Code, Kiro וחברים כדי לפתח קוד במהירות על ידי שימוש ב-AI.

## יתרונות
1. מהירות פיתוח גבוהה
2. פחות שגיאות
3. טוב יותר לפרוטוטיפים
4. טוב יותר להבנת קוד

## כלים זמינים
- Cursor Editor
- Claude Code
- Kiro
- GitHub Copilot
- Cody
